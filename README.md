# 🎓 University Grade and Attendance Tracker

## 📌 Project Overview

**University Grade and Attendance Tracker** is a Java-based application designed to help universities and students manage **student information, subject marks, grades, attendance, and academic performance** in an organized way.

The project demonstrates important **Object-Oriented Programming (OOP)** concepts such as classes, objects, encapsulation, inheritance, interfaces, method overriding, constructors, exception handling, and file handling.

---

## 🎯 Objectives

* Store and manage student information.
* Record marks for different subjects.
* Calculate total marks and average marks.
* Calculate attendance percentage.
* Determine student grades.
* Display complete student academic details.
* Store student data using file handling.
* Demonstrate Java OOP concepts in a practical project.
* Handle invalid input and runtime exceptions.

---

## 🛠️ Technologies Used

* **Programming Language:** Java
* **Concepts:** Object-Oriented Programming
* **Input:** Java `Scanner`
* **File Handling:** `FileWriter`
* **Exception Handling:** `try-catch`, `throws`, `IOException`
* **Development Environment:** Command Prompt / VS Code / IntelliJ IDEA / Eclipse

---

## 📚 OOP Concepts Used

### 1. Class and Object

Classes are used as blueprints for student-related data and operations, while objects represent individual students.

### 2. Encapsulation

Student information is managed using fields and methods to control access to data.

### 3. Constructors

Constructors are used to initialize student objects.

### 4. Inheritance

Inheritance can be used to create specialized student-related classes from a common parent class.

### 5. Method Overriding

Child classes can provide their own implementation of inherited methods.

### 6. Interface

Interfaces can be used to define common operations that different classes can implement.

### 7. Polymorphism

The project demonstrates how the same method or interface can work with different objects.

### 8. Exception Handling

Exceptions are handled using Java's `try`, `catch`, `finally`, `throw`, and `throws` mechanisms.

### 9. File Handling

Student information can be written to a file using Java's `FileWriter`.
